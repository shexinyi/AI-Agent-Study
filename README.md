# 《AI Agent 快速入门与求职实战》

面向有 **Python** 和 **Java** 基础、尚未做过 LLM 应用开发的工程师。目标是在 **6–8 周**内，建立可投递「AI 应用工程师 / Agent 工程师 / LLM 应用开发工程师」的能力与作品集。

正文 **34 章**与 **附录 A–D** 已完结。从 [全书目录](./00-全书目录.md) 或 [附录总目](./docs/附录.md) 查表；投递前按第 34 章走 30 分钟模拟。

## 怎么读

1. 先看 [00-全书目录.md](./00-全书目录.md)，对照自己的周计划打卡。
2. 每一章是独立 Markdown，可直接转 PPT。
3. 章内代码均可运行；完整工程在 `code/chXX/`，与正文保持一致。
4. 没有 API Key 时，优先跑「规则 Agent / Mock」示例，再接真实大模型。

## 环境总览（后续章节会细化）

- Python：标准库示例按 3.10+ 写。**3.10 已于 2026-10 结束官方支持**，新环境用 3.11。2026-11-11 起 `langchain` 1.5 / `langchain-core` 1.8 也要求 3.11；第 17 章仍钉 `langchain-core==1.6.1`
- Java 17+（推荐 17 或 21），Maven 3.9+
- 接 OpenAI 真接口时看 [附录 B](./docs/附录B-常用模型与接口速查.md)（2026-11-12）：新项目用 Responses；`gpt-4o-mini` 将于 2027-01-14 关闭。章内默认模型名是教学字符串
- 可选：OpenAI / Anthropic / 任意 OpenAI 兼容国产模型的 API Key
- 第 10 章起可选：`chromadb`（装不上可用章内 JSON 文件库）
- 第 11 章可选：`pymilvus`（Lite 失败时用章内 MiniMilvus 教具）

## 学习契约

- 不要求你先懂机器学习或训练大模型。
- 要求你能写函数、类、基本异步，以及一个能跑起来的 Spring Boot 接口。
- 每一章结束都有「面试考点」和「课后练习」，请当真做，而不是只看。
